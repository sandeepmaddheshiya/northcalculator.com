- **Q23 resolved (2026-11-24):** CPI-U annual averages 1913–2025 are in `src/calculators/finance/inflation/cpi.json`. The keyless v1 API returns monthly values only for year ranges, so `scripts/fetch-cpi.mjs` computes BLS's annual mean at published precision and takes M13 values from the latest-years response (2025's October value was never collected). Refresh with `pnpm cpi` after each January release; a BLS key (BLS_API_KEY) avoids the daily request limit.
